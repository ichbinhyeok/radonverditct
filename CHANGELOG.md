# Changelog

All notable changes to RadonVerdict are documented in this file.

## [0.1.0.0] - 2026-08-27

### Added

- Evidence-first homepage, result interpretation, controlled county evidence, and search-intent pages.
- Private, expiring action-plan handoff links with hashed tokens and privacy-filtered product telemetry.
- Automated sitemap, canonical, JSON-LD, internal-link, and cache-policy contracts.
- Source-linked county evidence profiles and downloadable data-oriented navigation.

### Changed

- Reduced the public SEO surface from broad modeled-cost pages to 29 defensible indexable URLs.
- Moved inspector tooling outside the indexable core and retired unsupported cost and guide surfaces.
- Added dated editorial ownership, transparent review status, and public-source references.
- Applied cache policies for public documents and static assets while preserving private no-store responses.

### Fixed

- Removed internal links from indexable pages to retired 410 routes.
- Removed the production fallback admin password and disabled SQL logging by default.
- Extended deployment health checks to validate the sitemap and robots contract.
