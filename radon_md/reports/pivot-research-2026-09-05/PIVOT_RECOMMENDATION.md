# RadonVerdict 피벗 결론

**결론부터:** 주제를 **“지역별 라돈 위험 정보”에서 “라돈 검사 설정·유효성·기록”으로 바꾸는 것**이 가장 낫다.

새 핵심 제품은 글 모음이 아니라 하나의 흐름이어야 한다.

> 어떤 검사를 고를지 → 어디에 둘지 → 조건을 어떻게 유지할지 → 검사가 훼손됐는지 → 언제 재검할지 → 결과와 조건을 기록·공유하기

이름을 붙이면 **Radon Test Protocol & Validity**다. 한국어로는 “라돈 검사 절차·유효성 도구”에 가깝다.

단, 이것도 성공 보장은 아니다. 지금 확인된 후보 중 **검색 가능성, 기존 자산 재사용, 수익화, 전문가 부재라는 제약을 동시에 가장 덜 위반하는 선택**이라는 뜻이다.

## 왜 이 주제인가

### 1. 자체 데이터에서 가장 가까운 수요가 이미 확인됐다

저장된 GSC 집계에서 `/radon-levels` 계열은 **91클릭 / 6,416노출**이었고, 비용 계열은 **8클릭 / 3,440노출**이었다. 전체 사이트도 한때 28일 동안 **261클릭 / 23,290노출 / 평균 순위 7.42**를 기록했다. 이 도메인이 라돈 검색에서 전혀 받아들여지지 않은 것은 아니다. 반면 3,126개 county 페이지는 평균 어휘 유사도 84.54%였고, 그 물량을 되살리는 방식은 같은 실패를 반복한다. 근거: [저장소의 복구 명세](../../spec/13_nextjs_evidence_based_salvage.md).

검사 절차는 기존의 `levels/testing`, 결과 입력, 행동계획, 공유 기능, 제휴 클릭 측정을 그대로 연결할 수 있다. 새로운 업종을 발명하는 피벗이 아니라, 과거에 검색 반응이 있었던 흐름의 **사용자 작업 하나를 끝까지 완성하는 피벗**이다.

### 2. 좋은 표본의 공통점은 “정보량”이 아니라 “작업 완료”다

공식 검색 결과에는 검사 기간·배치·조건에 관한 문서가 많다. CDC는 단기 검사를 2~90일, 장기 검사를 90일 초과로 설명하고 배치 원칙도 제공한다. 하지만 사용자는 여러 문서를 읽고 자기 상황에 적용해야 한다. [CDC 검사 가이드](https://www.cdc.gov/radon/testing/index.html)

반대로 잘 만든 독립 도구들은 다음 구조를 가진다.

1. 사용자의 구체적 상황을 입력받는다.
2. 공식 규칙을 짧은 결정 흐름으로 바꾼다.
3. 결과를 저장·공유·다운로드하게 한다.
4. 다음 행동이나 구매가 자연스럽게 이어진다.

RadonConnect도 이미 여러 라돈 도구를 묶고 있어 “계산기 하나”만으로는 부족하다. 차이는 **검사 전 준비부터 검사 기록까지 이어지는 단일 워크플로**에서 만들어야 한다. [RadonConnect 도구 목록](https://radonconnect.com/tools/)

### 3. YMYL을 없앨 수는 없지만, 위험한 판단에서 벗어날 수 있다

“이 집은 안전하다”, “암 위험이 얼마다”, “이 팬을 사서 직접 교체하라”는 주장에는 전문가 검토가 필요하다. 검사 도구는 그 대신 공식 절차를 출처와 함께 적용한다.

출력도 이렇게 제한한다.

- `safe / unsafe`가 아니라 `절차상 유효 / 훼손 가능 / 재검 권장`
- 질병 위험 예측이 아니라 공식 기준의 원문과 다음 단계
- 현장 진단이 아니라 입력된 검사 조건의 일관성 검사
- 주별 무료·할인 키트를 먼저, 상업 제품은 두 번째로 제시

EPA도 주정부 라돈 프로그램에서 무료 또는 할인 키트를 구할 수 있는지 먼저 확인하라고 안내한다. 이 순서를 지키면 제휴 링크 때문에 불필요한 구매를 유도한다는 불신도 줄일 수 있다. [EPA 검사 키트 안내](https://www.epa.gov/radon/how-do-i-get-radon-test-kit-are-they-free)

## 후보 점수와 탈락 이유

점수는 검색 진입 30%, 기존 자산 재사용 20%, 전문가 없이 운영 가능성 20%, 수익화 15%, 방어력 15%로 평가했다. 100점은 시장 규모가 아니라 **현재 RadonVerdict 제약 아래의 상대 적합도**다.

| 후보 | 점수 | 판정 | 핵심 이유 |
|---|---:|---|---|
| 검사 설정·유효성·기록 | **82** | 핵심 피벗 | 과거 levels/testing 반응, 제품형 검색 경험, 낮은 외부 의존도 |
| 설치 후 유지관리·증상 분류 | 68 | 보조 클러스터 | 실제 SERP 노출은 확인됐지만 안전 경계가 좁음 |
| 공식 데이터 출처 관측소/API | 64 | 해자 실험 | 차별화 가능하나 검색·결제 수요 미증명 |
| 결과 의미·건강 위험 | 41 | 축소 | 정부 우위가 강하고 YMYL 정면승부 |
| 비용 계산기 | 35 | 폐기 | 자체 GSC CTR이 약하고 경쟁 도구가 많음 |
| county/ZIP 위험 지도 | 28 | 폐기 | CDC·EPA·독립 지도가 이미 충족, 과거 대량생성 실패 반복 |
| 종합 주택 환경 리포트 | 22 | 폐기 | EPA MyEnvironment·GroundReport 등과 경쟁, 새 데이터가 많이 필요 |

[CDC는 county 측정 데이터를 이미 제공](https://www.cdc.gov/environmental-health-tracking/php/data-research/radon-testing.html)하고 [EPA는 zone 데이터를 중앙 제공](https://www.epa.gov/radon/epa-map-radon-zones)한다. 따라서 “전국 라돈 데이터가 있다” 자체는 해자가 아니다. RadonLevels, RadonCost, Ecosense도 이미 지도·ZIP 조회를 제공한다: [RadonLevels](https://radonlevels.org/), [RadonCost](https://radoncost.com/radon-by-zip/), [Ecosense](https://radonmap.ecosense.io/).

## 역설계한 최소 제품

페이지를 여러 개 먼저 만들지 않는다. `/radon-test-planner` 하나에서 아래 순서를 끝낸다.

1. **상황 선택:** 첫 검사, 확인 검사, 부동산 거래, 완화 후 재검.
2. **검사 방식 선택:** 단기·장기·연속측정기의 차이를 공식 출처와 함께 표시.
3. **배치 체크:** 층, 방, 높이, 벽·창문·습기원과의 관계를 체크리스트로 검증.
4. **조건 체크:** 시작·종료 시각, 문·창문, HVAC, 비정상 사건을 기록.
5. **유효성 판정:** 숫자 해석 전에 `valid`, `possibly compromised`, `retest` 중 하나를 근거와 함께 출력.
6. **검사 기록:** 입력값, 장치, 사진, 결과, 출처 버전을 PDF 또는 공유 링크로 저장.
7. **다음 단계:** 주정부 무료·할인 키트 → 일반 키트 → 연속측정기 순으로 선택지를 제시하고 제휴 관계를 명확히 표시.

SEO 페이지는 이 도구의 질문을 설명하는 소수의 지원 문서만 둔다. 예: `short vs long term`, `where to place`, `closed-house conditions`, `invalid test`, `when to retest`. 같은 답을 지역명만 바꿔 발행하지 않는다.

## 기존 데이터는 버리지 말고 역할을 바꾼다

공식 데이터는 **주제가 아니라 신뢰 기반**으로 쓴다. 현재 3,036개 county 레코드는 유용하지만, CDC와 주정부 값을 나란히 보존하지 않고 county FIPS당 마지막 소스가 앞 소스를 덮는 구조다. 따라서 지금 상태로 “독점 데이터”라고 부르면 안 된다.

장기적으로 만들 가치가 있는 것은 **Versioned Radon Source Registry**다.

- 원본 스냅샷·해시·수집일
- CDC와 주정부 수치의 동시 보존
- 평균·중앙값·최댓값·95백분위·4 pCi/L 이상 비율의 의미 구분
- 조사 기간, 표본 수, 억제 규칙, 검사 층·검사 유형
- 소스 변경·중단 알림과 라이선스

뉴욕은 export를, 미네소타는 다운로드를, 노스캐롤라이나는 별도 데이터 페이지를, 유타는 query builder를 제공한다. 형식이 흩어져 있다는 사실은 맞다: [뉴욕](https://www.health.ny.gov/statistics/environmental/public_health_tracking/about_pages/radon/export), [미네소타](https://mndata.web.health.state.mn.us/radon/data_download.html), [노스캐롤라이나](https://www.ncdhhs.gov/divisions/health-service-regulation/north-carolina-radon-program/nc-radon-data), [유타](https://ibis.utah.gov/epht-view/query/builder/radon/Radon/Average.html?Reload=x). 그러나 이것은 **데이터 정규화 기회**이지, 곧바로 검색 수요나 유료 API 수요의 증거는 아니다.

그러므로 API 전체를 먼저 개발하지 않는다. 공개 소스 카탈로그 한 페이지와 샘플 응답, 변경 알림 대기목록만 내고 반복 사용자가 생길 때 ETL을 고친다.

## 보조로 살릴 수 있는 기존 검색 자산

표본 검색에서 RadonVerdict의 과거 `radon fan noise troubleshooting` 페이지가 첫 결과로, 전기료 페이지도 상위 결과로 나타났다. 이는 설치 후 운영 주제에 대한 도메인 적합성을 보여준다. 다만 현재 URL은 410이고, 팬 선정·사이징·배선·교체는 전문가 부재와 충돌한다.

복원한다면 6~10페이지짜리 핵심 피벗이 아니라 다음의 **안전한 보조 클러스터**로 제한한다.

- manometer가 0이거나 평소와 달라졌을 때의 육안 확인
- 소음·gurgling·응축 증상의 분류와 전문가 호출 기준
- 유지관리와 재검 일정
- 전기료 계산
- 모델·보증·공식 문서 레지스트리 — 제품 추천은 하지 않음

EPA는 경고장치 확인과 최소 2년 간격의 재검, 팬 수명·교체 필요성을 안내한다. 이 범위 밖의 배선·팬 사이징·시스템 재설계는 다루지 않는다. [EPA 유지관리 안내](https://www.epa.gov/radon/how-do-i-know-if-my-radon-mitigation-system-working-properly)

## 30일 검증과 중단 기준

전체 리빌드 전에 도구 하나로 검증한다. 최소 30일 또는 **qualified organic 방문 1,000회** 중 늦게 도달하는 시점에 판단한다.

계속할 최소 조건:

- 도구 시작률 5% 이상
- 시작 대비 완료율 25% 이상
- 완료자의 기록 저장·공유율 10% 이상
- 제품 선택지 클릭률 2% 이상
- 실제 주문 1건 이상 또는 반복 방문·공유가 뚜렷한 사용자 집단

모두 미달하면 “SEO를 더 하면 된다”로 해석하지 않는다. 주제-제품 적합성이 없다고 보고 중단한다. API 실험도 45일 내 키 10개, 주간 반복 사용자 3명, 유료 대기 의향이 없으면 확장하지 않는다.

## 최종 의사결정

**메인:** 라돈 검사 절차·유효성·기록  
**보조 SEO:** 안전한 설치 후 유지관리·증상 분류  
**장기 해자 실험:** 공식 데이터 출처·버전 레지스트리  
**폐기:** county 대량발행, 일반적인 결과 의미 글, 비용 계산기 중심 전략, 종합 주택위험 리포트, 전문가인 척하는 팬 교체·사이징 조언

이 조합의 핵심은 “라돈 정보를 더 많이 쓰자”가 아니다. **사용자가 검사를 제대로 수행했다는 증거를 만들고, 공식 데이터가 어디서 왔는지 추적 가능하게 하는 제품**으로 바꾸는 것이다.

## 한계

- 이번 조사는 실제 키워드 볼륨 구매 데이터가 아니라 저장된 GSC와 2026-09-05 표본 SERP의 구성·결과 품질을 사용했다.
- SERP 노출은 위치·개인화·시점에 따라 달라질 수 있다.
- 과거 순위는 도메인 적합성의 증거이지 복구 보장이 아니다.
- 50개 주 데이터의 최신성·상업적 재사용 조건은 전수 재감사하지 않았다.
- 검사 규칙을 제품화할 때도 적용 지역과 출처 버전을 표시하고, 현장 진단·의료 조언으로 확장하지 않아야 한다.
